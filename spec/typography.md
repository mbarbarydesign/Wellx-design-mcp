# Typography

Fonts: **Manrope** (Latin, display + body) · **Alexandria** (Arabic RTL). Weights: Regular 400, Medium 500, SemiBold 600, Bold 700. All numbers `tabular-nums`.

## Ramp (size/line-height)
- text-xs 12/18 — small meta, chips (Medium); caps micro-labels: 11px SemiBold, UPPERCASE, +8% tracking, Gray/500
- text-sm 14/20 — dense body, table cells (Regular); supporting text in Gray/600
- text-md 16/24 — default reading body, forms
- text-lg 18/28 SemiBold — section & card headings
- text-xl 20/30 SemiBold — dialog titles
- display-xs 24/32 Bold — page titles (tracking -2%)
- display-sm 30/38 Bold — big metric numbers (tabular)
- display-md 36/44 Bold and up (display-lg 48/60, xl 60/72, 2xl 72/90 tracking -2) — marketing/auth only

Headings tracking -2%. Dense data UIs sit on text-sm/text-xs; reading surfaces on text-md.
