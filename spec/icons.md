# Icons

Library: **Lucide** (`lucide-react`). In Figma: Untitled UI icon set (visually equivalent; map names to Lucide in code).
- Sizes: 14 search inputs · 16 buttons/chips/inline · 18 nav/toolbar/topbar · 20 empty states/features
- strokeWidth **1.75** at every size; never mix filled and stroked styles on one surface
- Color = `currentColor` — icons never carry their own hex. Gray in chrome, white inside primary buttons, tone color inside alerts
- Directional icons (chevrons, arrows, panel toggles) mirror in RTL
- Icon-only buttons always get `aria-label` + `title`
