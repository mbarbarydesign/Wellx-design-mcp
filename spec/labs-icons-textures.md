# Wellx Labs — Iconography & textures

## Icons — one line system, 69 icons
24px grid, 1.6px stroke, round caps and joins. All drawn with `currentColor` so a single SVG
serves dark chrome and the light product.
- Color: `--wl-text-secondary` at rest, `--wl-accent` when active.
- Only AI & status icons carry color — the Copilot spark is the spectrum gradient; states use
  the fixed semantic set.
- Files: `docs/assets/labs/icons/*.svg` in this repo (69 SVGs, currentColor).

## Textures — spectral fields, dark & light
Six reusable backdrops (aurora mesh, orbital rings, signal grid, wave flow, particle field,
spectral horizon), each in a dark (brand) and light (product) variant, 1600×900 PNG.
- **One texture per view; ink/white base stays dominant** — 6–12% presence behind content.
- Dark set on the dark theme, `light/` set on the light theme.
- Use for empty states, card headers, hero panels, section breaks — never behind dense data.
- Command Center's signature backdrop is **spectral horizon**, anchored low so the top stays calm.
- Files: `docs/assets/labs/textures/` (+ `light/`) in this repo.
