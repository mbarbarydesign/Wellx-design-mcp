# Wellx Labs — Iconography, textures & material

## Icons — one line system, 69 icons (WX-N-10…15)
24×24 grid with a **2px safe margin (20px live area)**, 1.6px stroke, round caps and joins.
- Drawn with `currentColor` — one file serves both environments. Colour: `--wl-text-secondary`
  at rest, `--wl-accent` when active.
- **No fills, no two-tone icons, no corner radius above 2px.**
- Only AI & status icons carry colour — the Copilot spark is the spectrum gradient; states use
  the fixed semantic set.
- **No icon from an external set enters the product, ever.**
- Icons are never the sole label for a destructive action.
- Files: `docs/assets/labs/icons/*.svg` in this repo (69 SVGs). Set includes: underwriting,
  claims, policy, quote, premium, loss-ratio, reserves, treaties, brokers, customers, agents,
  billing, compliance, audit, ifrs-17, fraud-risk, dashboard, reporting, health-tpa,
  member-exp, copilot, ai-suggest, automate, signal, and 45 more.

## Textures — spectral fields (WX-N-16…18)
Six fields, each in a dark (brand) and light (product) variant, 1600×900 PNG:
**aurora mesh · loop field · signal grid · wave flow · particle field · spectral horizon**.
(Release 01 names the second field "loop field" — formerly "orbital rings"; asset filenames
keep the old name.)
- **One texture per view; ink or paper stays dominant.** Presence 6–12% on light, up to 40%
  on dark brand surfaces.
- Use for empty states, card headers, hero panels, section breaks — never behind dense data.
- Command Center's signature backdrop is **spectral horizon, anchored low** so the top stays calm.
- Fragment pattern tiles (ribbon repeat, loop field, signal grid, taper field — 16-unit
  repeat) are a related family for print/environmental; see labs-fragments.
- Files: `docs/assets/labs/textures/` (+ `light/`) in this repo.

## Material — the physical system
- Paper (primary): uncoated 120gsm natural white — documents, letterhead, book text.
- Paper (cover): Colorplan Ebony 350gsm or equivalent black through-dyed board.
- Finish: blind deboss for the mark; matt black foil for the wordmark. **No gloss, no spot UV,
  no lamination.**
- Metal: brushed aluminium, natural anodised — never polished, never gold, never rose.
- Acrylic: ink-black, matt face, 10mm minimum for wall-mounted fragments.
- Glass: frosted manifestation at 40%, using the 16-unit pattern tile.
- Textile: undyed cotton canvas or charcoal wool — no polyester, no branded lanyard print.
