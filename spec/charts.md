## Rules
- Lines 1.75 stroke, round caps, emphasized endpoint dot
- Grid: hairline border color only; axis labels 12px tabular Gray/500
- Area fills ≤ 12% tint of the line color
- Tooltip: mini card — radius 10, 1px border, soft shadow, 12px text
- Chart empty state: same pattern as component empty states
- Charts do NOT mirror in RTL
